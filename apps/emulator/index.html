Powered by EmulatorJS and Play! WebAssembly. Runs entirely in your browser.

Play your own game file

…or drop a game file here

Files are opened locally in your browser and are not uploaded anywhere. Only use games you own or that are free to distribute.

Game library

Homebrew games are freely distributable. Local games stay in apps/emulator/roms/ and are not bundled; only use games you own or can distribute.

Supported here: NES, Super Nintendo, Game Boy / Color, GBA, N64, DS, Mega Drive, Master System, Game Gear, PlayStation, PSP, and PlayStation 2. PS2 and PSP use a service worker to enable required browser isolation on compatible secure sites; first launch may reload once.
