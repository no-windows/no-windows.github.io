Free games (homebrew)

These are freely distributable games. Download each ROM from its page and save it into apps/emulator/roms/ using the file name shown (or edit games.json).

Supported here: NES, Super Nintendo, Game Boy / Color, GBA, N64, DS, Mega Drive, Master System, Game Gear, Atari 2600, PlayStation. N64, DS and PlayStation need a fairly fast device.
